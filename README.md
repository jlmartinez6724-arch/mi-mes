# Mi Mes Compartido v2.0
PWA familiar con autenticación, base de datos y sincronización en tiempo real mediante Supabase.

Archivos clave:
- `supabase-setup.sql`: crea tablas, funciones, políticas RLS y Realtime.
- `config.js`: conexión pública con Supabase.
- `SETUP_SUPABASE.md`: instrucciones completas.

No suba una clave `service_role` ni una secret key al repositorio.
